## 设计语言

| 角色         | HEX         | 用法                                                                                 |
| ------------ | ----------- | ------------------------------------------------------------------------------------ |
| 玄黑 ink     | `#141210` | 卡身 / 收边 / 封面封底 / 主文字。**禁整页铺黑，主底永远是冷灰**                |
| 冷灰底 paper | `#F1F1EF` | 主底色、留白默认背景（**是冷灰，不是暖象牙白**）                               |
| 冷漆红 red   | `#CE1432` | **唯一强调色，面积 ≤5% 只点睛**：花色 / 大数字 / 编号 / 价格 / 印章。永不铺底 |
| 奶白 cream   | `#EDEAE3` | 玄黑底上的一切文字与金句（**别用纯白**）                                       |

辅助灰阶（冷灰底上）：正文次级 `#5A544C` · 三级 `#9A948C` · 发丝线 `#D8D6D1`；玄黑底上：亮字 `#DCD7CE` · 注释 `#A39D93` · 暗线 `#3A3530`。
