## 0 · 动笔之前，先答八问（答不出就别开始写）

文案能力的下限，不是会不会写漂亮句子，而是能不能在发布前看出：**这条内容究竟是在帮助读者，还是在把我们的内部材料倒给读者。**

动笔之前，先回答（写前八问）：

1. 这条内容发给谁？
2. 这个人最近最可能卡在哪个具体问题上？
3. 这场活动正在回应什么问题？
4. 哪一个真实细节能让人感到现场存在？
5. 读者参加之后，能得到什么具体帮助？
6. 哪些信息只是内部完整性，删掉也不影响判断？
7. 这次应该写成朋友圈故事、群内总览、单场通知，还是资料更新？
8. 读完之后，最自然的下一步是什么？

八问答不出来，不应该直接开始润色句子——先去把信息搞清楚。

## 0.5 · 发出去之前：拿嘴念一遍

**发出去之前，拿嘴念一遍。** 自己念得累、念着别扭，客户看着更累——咱们的私董都是时间非常宝贵的人。

念完再问三个问题（斯斯原话，每次发之前都过一遍）：

1. **我能为你解决什么问题？**
2. **为什么这条内容要看下去？**
3. **接下来我要做什么动作？**

三个都答得出来，发。有一个答不出，回去改。

## 1 · 我们的私董是什么人（决定文案怎么写）

自己当家的老板。时间贵、判断快、讨厌被推销，但真心烦「招人、放权、找助理、业务卡壳」这些事。所以：

- 她们不关心我们团队在忙什么，只关心**这和我有什么关系**
- 她们对「闭门」「不对外」「仅限私董」有感觉，对权益清单无感
- 她们识别 AI 腔和广告腔的能力，比一般用户强得多

## 1.5 · 一条总心法：把活动写成一个正在发生的现场

一条活动文案不是把资料转述给别人，也不是把议程压缩成几段。它要完成一次转换：**从「读者此刻的问题」到「我想靠近这个现场」。**

斯斯改稿时真正做的事，是把活动从「我们有什么安排」改写成「一件正在发生、值得靠近的事」：

- 群里最近反复出现了什么问题 → 所以有了这场活动
- 谁会到场、为什么是她 / 他讲最合适
- 这次现场有什么独特的关系和细节（谁的办公室、哪个老私董来讲）
- 参与的人会怎么一起把问题推深
- 为什么这件事只在私董内部发生

**支撑现场感的，是「能改变判断的事实」**——不是形容词，是这六样：

| 能改变判断的事实 | 例子 |
|---|---|
| 真实场地 | 润宇老师的办公室 |
| 真实人物 | 斯斯下周二到杭州、张哥闭门复盘 |
| 真实参与者 | 今年进私董的都是业务很强的老板 |
| 真实合作经历 | 十一参与启元最新一期 vlog 广告 |
| 真实时间节点 | 马上就到双十一了，广告的活儿少不了 |
| 真实的闭门边界 | 这期不公开对外 |

这些细节让读者自己得出「这场值得去」的结论——**不需要我们替她总结「高端、稀缺、头部」。**

## 2 · 朋友圈怎么写（助理 / 运营视角）

### 2.1 身位：靠谱管家，不是打工人

你发朋友圈的身份是「坐在前排、掌握一手资源的运营管家」——

- **不是斯斯本人**：绝不冒充第一人称。用「斯斯下周飞杭州」「我们张哥」「我们私董群里最近在聊」这样的团队口吻。
- **不是汇报工作的员工**：开头写「这段时间我们在忙……」= 直接报废。
- **是那个有内部消息、热情靠谱的管家**：一手场域信息（润宇老师的办公室、哪个老私董要来讲、私董群里在聊什么）是你最值钱的资产，比文笔值钱。

### 2.2 结构：五段式

| 段 | 写什么 | 例（股东小会 2.0 实例） |
|---|---|---|
| ① 痛点开头 | 1–2 句老板的痛点提问，拍在脸上 | 「小团队到底怎么招人、放权还不翻车？」「IP怎么找到心仪的助理，并且培养成靠谱的中层？」 |
| ② 给解法 | 这件事我们怎么解决、在哪解决 | 「这俩都是我们最近私董群里高频的问题，来来来，我们每月一次的股东小会，一起解决它。」 |
| ③ 时间地点人 | 下周二、杭州、润宇老师办公室、斯斯和张哥，一个屏内收拢 | 「下周二（9 月 15 号），斯斯抵达杭州……尤其是在润宇老师的办公室召开」 |
| ④ 现场细节 | 同桌是谁、现场有什么独特关系（用事实，不用形容词） | 「今年进我们私董的都是业务很强的老板」「他（润宇）会不时过来看看咱们讨论得怎么样了」 |
| ⑤ 收口 | 不罗列权益，用真实的边界卡门槛、给一个轻动作 | 「这期就不公开对外了，嘿嘿，这是我们私董的价值。想加入的老板们，评论区或私戳我，先聊聊看。🥂」 |

### 2.3 风格红线（照《对外文案风格规范》，违一条就改）

- 开头禁「我们最近在忙什么」一切汇报式语言
- 禁金句体、一惊一乍短句堆叠、「不是…而是」排比
- 禁塑料词：解锁、赋能、抓手、闭环、护城河
- **禁用形容词造势**：「高端、稀缺、顶级、头部、高势能」这类词自己不出力——用 1.5 节那六样真实事实，读者自己会得出结论
- 权益清单不进朋友圈——那是产品页的事
- 有人味：来来来、嘿嘿、🥂 这种语气词是允许且加分的
- 字数：能一屏扫完就别两屏。前三行折叠线之后的内容，默认没人看

### 2.4 朋友圈提示词（直接复制给 AI）

```

写作规则：
1. 身位：助理视角，绝不冒充斯斯第一人称。用「斯斯下周飞杭州」「我们张哥」「我们私董群里最近在聊」的团队口吻。
2. 开头 1–2 句必须是创业老板最焦虑的痛点提问（招人、放权、找助理、带骨干、业务卡壳），禁止任何「我们最近在忙什么」式开头。
```

## 3 · 群公告怎么写

### 3.1 硬标准（9.11 复盘会定的，再犯就复制粘贴这段给 TA）

1. **一条公告 = 一个信息点，最多两个**（一个新活动 + 一个交付合集）。今天发一个，明天发一个，都能接受。
2. **结尾不复述前文。** 删掉结尾两段信息量没损失，就删。
3. **绝不做垃圾信息回收站。** 三场活动塞一条 + 资料更新 + 重复提醒 = 老板扫一眼眼花缭乱，什么都没记住。

**拆分是手段，不是目的。** 如果成员确实需要一个月度视图（比如月初、或者密集迎新时），可以做总览——前提是总览短、清楚、有重点，具体活动再单独写。真正的标准只有一条：**成员能不能轻松看懂。**

### 3.2 三种合法形态

**形态 A：活动总览**（三场以上活动时用，一张表收拢，不逐场展开）

> 各位私董，🔔咱们 9 月的行程来了，有三场活动可以参与：
> 1️⃣ 9月13日（本周日）｜北京商业下午茶 —— 坐标、席位余量、怎么兑换
> 2️⃣ 9.15（下周二）杭州｜股东小会 —— 主题、坐标、谁讲、私董免费
> 3️⃣ 9.20（周日）线上｜内训 —— 主题、时间、嘉宾是谁（身份+跟社群的关系）

总览里每场只保留**能改变判断的事实**：日期、地点、主题、一个核心卖点。不放完整议程，不塞报名、权益、兑换。

**形态 B：单场活动通知**（一场重点活动单独写透，顺序固定）

1. **为什么是现在**（「马上就到双十一了，广告的活儿肯定少不了」）
2. **群里哪些人会用到**（「群里有很多 IP 和新手博主」）
3. **嘉宾为什么有资格讲**（身份 + 真实合作经历 + 跟社群的关系：「十一是百万粉的视频编导，也是咱们两年的老私董，参与启元最新一期 vlog 广告」）
4. **用一个真实项目说明这场会怎么讲**（「这次带大家看头部团队如何完成一条真实商单」）
5. **按项目过程写能带走什么**——前期怎么摸清客户诉求、中期多团队怎么配合、后期卡点怎么给客户交代。**把课程目录翻成工作过程**，做 IP 的人一看就知道自己需不需要
6. 自然带出相关资料（「一个讲前端商务怎么搞定大客户，一个讲后端内容怎么极致交付，双十一前把这俩闭环打通」——把资料解释成同一条业务链，不是甩链接）
7. 时间、形式和下一步

**形态 C：资料上新**（当资产运营，不当更新通知）

> 【女商私董·资产库上新】……已全部完成剪辑，正式入库：
> 给身份（满血版商业播客）、给听法（适合谁在什么场景听）、给预告（小程序什么时候上）、给兜底（有问题随时 call 我）。

### 3.3 每场活动的写法

- **标题写痛点问题，不写主题描述**：「IP，如何做好一期视频广告？」✓ 「如何配合百万博主拍广告」✗
- **嘉宾写「身份 + 跟社群的关系」**：「十一是百万粉的视频编导，也是咱们两年的老私董」✓ 「五百强企业高管」✗
- **地点写到有画面**：「润宇老师办公室（西湖科技大厦）」✓ 「西湖科技大厦C座」✗
- **准入和收费写死**：谁能来、免费还是另付费、找谁报名——8 月错题（只写主题没说准入和免费）的教训，永久生效。

## 4 · 校准提示词（万能版——任何文案，先过它）

不知道该写成朋友圈还是群公告、素材一团乱的时候，用这条。它先判断、再动笔，还会告诉你删了什么、什么待核。

```
你在帮女商写一条私董运营文案。

先不要改句子。先判断：
1. 渠道是朋友圈、私董群总览、单场活动通知，还是资料更新；
2. 读者是谁；
3. 读者现在最可能卡在哪个具体问题；
4. 这场活动正在回应什么问题；
5. 哪些真实人物、地点、合作经历或参与者能让现场成立；
6. 哪些信息只是内部资料，删掉也不影响读者判断。

写作要求：
1. 从读者能认出的具体问题开始，不从「我们最近在忙什么」开始。
2. 先让读者知道为什么和自己有关，再介绍活动。
3. 把活动写成一个正在发生的真实现场，不要写成课程目录。
4. 只保留能改变读者判断的事实：真实人物、真实场地、真实案例、真实参与者、真实时间和边界。
5. 把议题翻译成读者参加后能解决的具体问题。
6. 如果是朋友圈，可以用自然口语、轻微玩笑和熟人之间的邀请感；不要写成「高端」「高转化」式营销话术。
7. 如果是私董群总览，保持短、清楚、有重点；需要时把总览和单场通知拆开。
8. 不要把活动、资料、权益、报名、兑换和提醒全部塞在一条消息里。
9. 不要编造嘉宾履历、场地关系、人数、权益和时间；缺信息就标「待核」。
10. 结尾给一个自然、低压力、符合关系的下一步，不要强行催报名。

输出：
第一，渠道、对象和核心问题；
第二，建议保留的 3-6 个事实；
第三，文案；
第四，删掉了什么，以及为什么删；
第五，仍需人工确认的事实。

原始素材：
【粘贴素材】
```

## 5 · 朋友圈不只发招募：四种日常内容

招募文案（第 2 节）只是朋友圈的一种。日常还有四类，让潜在成员看见群在发生什么、适合什么人——同时守住群内隐私：

| 类型 | 写什么 | 一句话口诀 |
|---|---|---|
| 真实结果 | 匿名讲一次连接、一个判断、一个项目怎么往前走 | 写「做成了什么」，不写「群里很热闹」 |
| 成员优先 | 先讲私董能优先参加 / 体验 / 看到什么 | 让会员觉得这张票值 |
| 现场切片 | 讲一场活动正在解决的具体问题 | 别把内部议题目录整段搬出去 |
| 价值观与边界 | 审核制、保密、参与义务 | 让想来的人知道这里的相处方式 |

三条硬规矩：

1. **每条朋友圈只留一个主动作**：报名、申请、查看回放、了解私董——四选一，不堆多个转化入口。
2. **成员姓名、聊天截图、合作金额、群内原话**，发布前必须拿到授权并脱敏。
3. 资料放长线：长期资料进年度回放合集、权益规则进固定说明页，朋友圈不背包袱。
