# 女商业务背景（整合版）

**日期**：2026-09-11（260911 录音 + docs/reference 私董运营方案 1.5 + 私董运营文案手册 v2.0 整合）
**用途**：文案工作台（/copywriting）提示词模板设计与维护的业务基准。模板种子见 `apps/api/drizzle/0031_copy_templates_seed.sql`。

## 一盘生意，两端

- 主体渠道：**两个女性商业音频播客**；斯斯是 IP 本体。
- **B 端**：接广告、品牌合作。
- **C 端**：服务自己的客户，按客单价从低到高是一条产品阶梯。

## C 端产品阶梯（便宜 → 贵）

1. **365 连麦**（微博）：入门产品。客群最初阶——职场女性、刚开始或尚未创业的女性；困惑是职场出路、副业、要不要起步创业这类初阶问题。
2. **商业下午茶**：5–6 人同桌的商业战略工坊，名叫下午茶、含金量极高；卖两类票——上桌席位 + 旁听席位。
3. **1V1 咨询**：更精准、更沉浸、更有隐私的重咨询，斯斯对职场/商业做较重的判断和建议。
4. **女商私董社群**：高客单、审核制、年度，100+ 人。以 IP 行业为主、已跑完 0→1、正在经营 1→10/1→100 的女性创业者；群内还有品牌方、流量方、各领域专家，互相提供资源、撮合和碰撞。

## 渠道版图

- 公域主体：两个商业播客。
- 私域：十几个小助手人设号经营十几万级私域（朋友圈 + 听友群）+ 私董群。
- 今年新上：微信小程序 AI 问答智能体——承接初阶客户（黏在私域内 + 低价获得斯斯的商业判断），是未来私域经营媒介。

## 三层客群

1. **私董群成员**：时间贵、身价贵、注意力贵；要的是真实商业/管理/规模化问题和有价值的渠道资源。
2. **私域客群**：以偏初阶为主，对商业/女性商业/创业感兴趣，含部分高净值但未入私董。**关键：绝大部分私域客户对斯斯的所有产品陌生——不能假设他们知道产品是什么、什么价、有什么用。**
3. **公域受众**：刚接触到斯斯内容的人，对斯斯和产品都更陌生。

## 私董群三类核心交付

1. 商业下午茶全年多场实战录音（群内可听）；
2. 全年多场内训（各领域专家专题课）；
3. 资源/流量撮合（广告商、品牌方与群内高质量 IP 互相看见）。

## 内容话题三类（决定 goal 维度怎么分）

1. **宣传私董群交付** → 让公私域的人产生兴趣和向往 → 了解、加入、付费。
2. **空档转化**：下午茶/1V1 排期出来了 → 让有诉求的人第一时间付费预约（私董和非私董都可买）。
3. **日常信息**：好玩的事、品牌合作 → 抬斯斯 IP 和圈层的含金量。

## 产出渠道四类

1. 朋友圈（私域）；
2. 私董群公告（受众=私董）；
3. 公域渠道（播客 show notes 等）；
4. 听友群 / 小程序内测群（更活跃的私域客户集体）。

## 风格底线

- 说人话、像说话、亲切告知；**不能像通知、不能像文字稿、不能像卖弄信息**。
- 要有斯斯的味道；轻语气词加分（来来来、嘿嘿、🥂）。
- **身份必须清楚**：以助手身份、以团队身份、还是以斯斯本人身份说，是很大的差异——绝不可混淆冒充（朋友圈默认团队管家口吻，不冒充斯斯第一人称）。
- 长度：一屏扫完；前三行（折叠线前）必须让人看出「这和我有什么关系」。
- 发布前拿嘴念一遍，念着累就删。
- 红线明细（禁汇报式开头/金句体排比/塑料词/形容词造势/一条≤2 信息点/结尾不复述/不编造标「待核」/授权脱敏）见《私董运营文案手册_风格与提示词_260911.md》与 `copy_templates` polish 维度两条种子模板。

## 维护口径

- 价格、场次等数字**一律不写死**进模板：以系统记录为准，没把握标「待核」。
- 模板词表在「文案工作台 → 模板管理」维护（admin/operator）；system prompt 在「系统设置 → 文案工作台」维护（admin），未配置走内置默认（女商红线版，见 `apps/api/src/modules/copywriting/prompts.ts`）。
